# Between the Frames — The Power of Sequencing

An interactive CCT360 Lab 03 project using exactly three original SVG illustrations in two different orders.

- **The reunion:** empty platform → letter → meeting.
- **The farewell:** meeting → letter → empty platform.

Select a story, click a frame, use previous/next, or play the sequence. JavaScript variables track the story, active frame, and playback timer; functions and event listeners update the DOM, image order, captions, and interpretation. Controls work with a keyboard and include accessible labels.

## Run

Open `index.html` in a browser. No build or dependencies are required. Fonts use Google Fonts, with local system font fallbacks. All three images are included in `images/` and were created for this project.

## Submit with GitHub Pages

1. Create a GitHub repository and add its URL as the Git remote.
2. Commit progress with the message `Class Progress` and push to GitHub.
3. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the pushed branch and **/ (root)**, and save.
4. Submit the repository URL and the live URL shown by GitHub Pages.
